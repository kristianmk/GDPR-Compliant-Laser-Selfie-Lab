ULTRA HDR JPEG
==============

Encoding model:
  - Primary image: ordinary SDR JPEG, quality 0.95
  - Secondary image: logarithmic gain-map JPEG, quality 0.90
  - Gain-map dimensions: one quarter of primary width and height
  - Primary colour profile: embedded sRGB ICC
  - Ultra HDR v1: GContainer XMP, gain-map XMP, and MPF
  - Cross-platform metadata: ISO 21496-1 APP2 in both JPEG images
  - Legacy behavior: standard viewers display the SDR primary image
  - HDR behavior: compatible viewers reconstruct the HDR rendition from the gain map

Built-in pre-download validation:
  - primary and secondary JPEG structure
  - GContainer gain-map directory and declared secondary length
  - MPF primary size, secondary size, and secondary offset
  - embedded gain-map JPEG
  - gain-map XMP required fields
  - primary sRGB ICC profile
  - ISO 21496-1 primary and secondary metadata
  - ISO version 0, one channel, base colour space, forward direction
  - common denominator and all rational fields
  - numerical agreement between XMP and ISO metadata
  - non-zero HDR headroom

TRUE HDR PNG
============

Built-in pre-download validation:
  - PNG signature
  - IHDR: 16-bit RGBA
  - cICP: BT.2020 primaries, PQ transfer, RGB matrix, full range
  - mDCV: mastering display metadata
  - cLLI: MaxCLL and MaxFALL
  - CRC validation for metadata chunks
  - IDAT presence

Independent no-laser test:
  Dimensions: 160 x 120
  Pixel format: rgba64be
  Range: full
  Primaries: BT.2020
  Transfer: SMPTE ST 2084 / PQ
  cICP bytes: 09 10 00 01
  Mastering luminance: 0.0001 to 2000 nits
  MaxCLL: 954.4116 nits
  MaxFALL: 286.2783 nits
  PNG chunks: IHDR, cICP, mDCV, cLLI, IDAT, IEND
  CRCs: valid
  Deflate stream: valid
  Scanline filter: PNG Sub filter

Independent laser test:
  Dimensions: 240 x 180
  Pixel format: rgba64be
  Range: full
  Primaries: BT.2020
  Transfer: SMPTE ST 2084 / PQ
  Mastering luminance: 0.0001 to 2000 nits
  MaxCLL: 1849.4450 nits
  MaxFALL: 127.2987 nits
  Built-in HDR validator: passed

Interpretation:
  The HDR JPEG is an Ultra HDR gain-map file with a normal SDR fallback, not
  an ordinary SDR JPEG carrying only an HDR label. The HDR PNG contains direct
  16-bit BT.2020 PQ samples. Both are technically HDR delivery formats.

Source limitation:
  When the input image is SDR, inverse tone mapping creates a genuine HDR output
  signal or rendition but cannot recover highlight or shadow detail already
  clipped in the original capture or browser decode.
